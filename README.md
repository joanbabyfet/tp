## About
使用 thinkphp8 集成常用功能与业务场景, 代码分层使用 Service 做主要的业务处理

## Feature
* 多应用
* .env多环境
* JWT令牌
* 图片上传与缩略图功能
* 图形验证码功能
* 发送短信功能, 使用策略模式
* 发送邮件功能
* 发送fcm推送消息
* 发送telegram消息
* 第三方支付功能, 使用策略模式
* websocket服务端
* 定时任务功能
* 队列功能
* 多语言功能
* 限制访问频率中间件
* 迁移文件功能
* 视图模板
* 日志功能

## Requires
php 8.0+
